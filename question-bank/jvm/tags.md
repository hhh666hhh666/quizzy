# JVM 题库标签词表

> **受控词表**。`plan.py` 切分时**只从这里挑**标签——挑的是在标题或正文里出现过的，标题里出现的优先。
> 新标签要先加进本表再用，否则它不会进 `tasks.json`、模型也就不会去用它。
>
> 两点说明：
> - **考频档位**（`高频` / `中频` / `低频`）**不在此表**——它由出题环节按原文信号单独标，口径见技能的 `references/authoring.md`。
> - 标签全库同名复用（quizzy 的标签是全局共享的），所以**别为同一概念造两种写法**（如 `记忆集` 与 `Remembered Set` 只能留一个）。
> - 内容标签每题 ≤ 5 个；下表按 2026-10-16 首跑前对 `md/JVM.md` 做的术语词频统计排列，新增的放末尾即可。
