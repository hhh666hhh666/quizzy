# 面向用户的功能展望

> **定位**：这份文件是**方向素材**——只说「面向用户，功能上还能怎样」，**不是待办、不排期、不代表承诺**。
> 一旦某条收敛为「决定要做」，**迁去 [`../todo/`](../todo/)**（未决事项唯一入口），本文件只留一行链接，不复述。
>
> **不复制现状**：现有功能见 [`../../README.md#功能`](../../README.md#功能) 与 [《需求范围》](./scope.md)；下表的「现状缺口」只是概览，**细节以代码为准**。
>
> **维护**：改动面向用户的功能后，回来**核对并修正**表里的「现状缺口」列——过时的就地改，**别新增条目当待办**。
>
> **真相源**：本文件。

## 可以新增

| 方向 | 用户价值 | 现状缺口 | 备注 |
|------|----------|----------|------|
| 找回密码 | 忘了密码也能自救，不必人工介入 | 账户自助已含「改密码」，但**忘了**密码时无法自救 | 依赖发信通道，见 [邮箱验证](../todo/2026-10-01-TODO-邮箱验证.md)；已落地的账户自助（改密码 / 改昵称 / 改头像 / 注销账号）见 [ADR 0027](../adr/0027-token-version-invalidates-all-devices.md) |
| 邮箱验证 | 可找回的前置，也挡批量注册 | 注册不校验邮箱 | 同上；关联 [注册风控](../todo/2026-10-03-TODO-注册风控.md) |
| 微信登录 | 移动端 / 小程序低摩擦进入 | 仅用户名密码 | [微信登录与账号绑定](../todo/2026-10-03-TODO-微信登录与账号绑定.md) |
| 个人数据导出 | 带走自己的作答记录与错题 | 导出只覆盖题库（Excel / JSON） | 属个人数据，非「新导入格式」 |
| 题目收藏 / 标记 | 自己的「待再看」清单 | **已具备**：多收藏夹 + 默认收藏夹 + 夹简介；题库页可按夹筛、可批量归类，夹内可一键开练习 | 取舍见 [ADR 0030](../adr/0030-favorites-as-named-folders.md)；**只落 PC**（移动端无收藏入口） |
| 题目笔记 | 记自己的理解与坑 | 无 | |
| 分类 / 标签管理入口 | 批量整理归类 | 分类 / 标签的增改嵌在题库编辑流程里，无独立视图 | 断言以代码为准 |
| 复习计划 / 每日一练 | 给出复习节奏，不靠自觉 | 无计划、提醒、目标类功能 | |
| 公开题库订阅 / 分享 | 复用别人整理好的题 | 归属只有「公开题 / 我的题目」二元（[ADR 0003](../adr/0003-public-questions-by-empty-owner.md)），无订阅 | |
| 公开收藏夹 / 夹分享 | 把自己整理好的夹分享给别人照着练 | 无任何分享行为：夹的 `is_public` 开关**存而不用**（面板能开、别人看不到，见 `FavoriteFolder` 实体注释与 [ADR 0032](../adr/0032-glass-overlays-and-folder-intro.md)）；夹与题都无对外只读视图 | 字段伏笔已留，做之前先定「公开的颗粒度」（整夹只读？带练习入口？） |

## 可以改进

| 现有功能 | 改进点 | 用户价值 | 备注 |
|----------|--------|----------|------|
| 规则卷抽题 | 按标签抽题、难度**配比**控制 | 出卷更可控 | 规则卷 UI 已支持分类（单选）/ 题型 / 难度的多选与题量；标签维度后端字段已备（`tagIds`）UI 未接；「分类多选 + 未分类」与题库页筛选的对称性见 [筛选能力延伸](../todo/2026-10-05-TODO-筛选能力延伸.md) |
| 错题本移出 | 「连续答对几次移出」可配置 | 贴合个人节奏 | 现为固定阈值 |
| 导入 | 错误报告可下载、导入前预览 | 大批量导入更可控 | |
| 答题页 | 键盘快捷键（选项 / 下一题 / 提交） | PC 答题提速 | |
| 历史记录 | 按题库 / 试卷维度汇总 | 看自己在哪类题上弱 | |
| 题库 | 批量操作（批量删除 / 改分类 / 加标签） | 整理效率 | 已具备：跨页批量选择 + 「加入已有试卷 / 用所选新建试卷 / 加入收藏夹」（2026-10-06）；批量删除 / 改分类 / 加标签仍缺 |
| 移动端补齐 | 错题本 / 记录 / 只读试卷列表 | **已具备**：三页初版（2026-10-10）——错题本可翻页 / 手动移出 / 一键练错题；答题记录按状态分色（进行中可续答、已完成看结果、已放弃不可点）；试卷只读列表可一键开始答题。**收藏夹仍无移动端入口** | 移动端只做只读消费，取舍见 [ADR 0019](../adr/0019-mobile-clients-with-uniapp.md)。[移动端与小程序落地](../todo/2026-10-03-TODO-移动端与小程序落地.md) |

## 可以深化

| 功能 | 可深化的地方 | 备注 |
|------|--------------|------|
| 快速练习 | 支持更多抽题条件（分类多选等） | UI 已含分类（单选）/ 题型 / 难度 / 题量 / 排除最近 N 天作答；标签维度后端已备（`tagIds`）UI 未接 |
| 试卷 | 复制试卷、调整题序 | 无复制、无题序调整接口（`sort` 仅在新建 / 追加时按末尾递增） |
| 错题本 | 一键把错题组成本次试卷 | 目前是「重练」 |
| 题库 | 题目变更留痕 | 现在改题就地改，见 [《数据模型》](../design/数据模型.md) |

## 与范围边界

上表条目凡与 [《需求范围》](./scope.md)「**明确不做**」冲突的，**动手前先改 scope 与对应 ADR**，不要当待办排期：

- 统计看板、掌握度分析 —— 由练习语义推出不做（[ADR 0001](../adr/0001-practice-not-exam-semantics.md)）
- 限时 / 排名 / 防作弊、非选择题型、图片与富文本

移动端 / 小程序仍只做「消费」，**不新增业务能力**（[ADR 0019](../adr/0019-mobile-clients-with-uniapp.md)）——上表里建设类改进默认只落 PC。
