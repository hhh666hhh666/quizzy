### 本次定下的叫法

这些在同一会话内已由 domain-modeling 落进 [CONTEXT.md](../../CONTEXT.md)，此处只做罗列备查：

- **会话** = 用户某一次完整的作答过程（含题目、作答与判分结果）。不是"答卷"；"答题记录"只是列表页标题。
- **作答** = 用户对一道题提交的选择，可留空表示跳过。**答案**专指正确答案，两个词不再混用。
- **公开题** = 不属于任何人的题目，所有人可读、谁都不可改。
- **我的题目** = 用户自建、只有本人可改的题目。
- **错题本** = 从作答统计投影出来的状态集合，不是实体、无对应表。
- **题目契约** = 批量导入时一道题必须满足的字段约定。
- **错误行** = 导入时校验不通过、被单独跳过的题目。
- 另明确：**本项目没有「知识点」概念**，一道题考什么靠分类 + 标签组合表达。
