# 移动端（H5 与微信小程序）

**目的**：说清移动端的定位与边界——它做什么、不做什么，以及和 PC 端、和后端的关系。

**读者**：要改移动端的人；判断某个功能该不该进移动端的人。

**真相源**：**路由、页面清单、组件与 API 边界以代码为准**（`quizzy-mobile/src/` 下的 `pages.json`、`pages/`、`api/`、`stores/`、`components/`）。本文档只讲边界与约定，不复制那些清单——与 [《前端》](前端.md) 的演化路径一致。

---

## 定位与范围

移动端是 PC 之外的**新客户端形态**，**只做「消费」**：

- 答题（逐题作答、即时判分、断点续答）
- 快速练习（按条件随机抽题）
- **只读的试卷列表** + 从已有试卷开始答题（不做新建 / 编辑 / 删除）

**当前已落地**：登录/注册、快速练习、答题、结果这 4 个页面（一条主线）。
错题本、答题记录、只读试卷列表尚未实现。

「建设」类功能——题库增删改查、组卷、Excel / JSON 导入导出——**留在 PC**。
理由与取舍见 [ADR 0019](../adr/0019-mobile-clients-with-uniapp.md)；它只新增入口、不新增业务能力，见 [《需求范围》](../requirements/scope.md)。

## 与 PC 端的关系

- `quizzy-web`（PC，Vue3 + Element Plus）**完全不动**；移动端是**全新工程、全新移动设计**，不是把 PC 页面压窄。
- 两端**共用同一后端与同一账号**。
- 移动端与小程序共用同一份代码，差异用条件编译处理。

## 工程与编译目标

- 顶层目录 `quizzy-mobile`，与 `quizzy-server` / `quizzy-web` 并列；**未引入** monorepo 工具链。
- 基于 **uni-app（Vue3 + TypeScript + Vite + Pinia + wot-design-uni）**。
- **当前只启用 H5 编译目标**；`mp-weixin` 已在 `manifest.json` 留占位，但**未装依赖、未接入**，等备案与 AppID 就绪再做。
- 工程为**手写最小脚手架**，不是 `degit` 官方模板（模板依赖 GitHub 拉取，在本机环境的代理下不可靠）。

## 页面流与信息架构

一条主线与 PC 同构，但页面按移动交互重新设计：

登录 → 快速练习 → 答题 → 结果。

**当前不设 tabBar**：只有「首页」与「快速练习」两个平级入口，其余都是流程内页；等错题本 / 记录 / 试卷列表进来后再统一设计。

## 与后端的边界

- 复用现有 `/api/**` 接口，**后端不改**。
- 从已有试卷答题走 `QuizStartDTO.sourceType = PAPER`（另有 `QUICK` / `WRONG_BOOK`）。
- 接口的**确切路径、字段与错误语义以 springdoc 为准**，见 [《API》](API.md)——本文档不复制接口清单。
- 后端 JSON 配了 `non_null`：**为 null 的字段整体不出现在响应里**（如未完成会话没有 `finishTime`），读取时要容错，别假设字段一定存在。

## 约定（改之前先看这两条）

- **Markdown 渲染只有一个边界**：`src/components/MarkdownRenderer.vue`。当前实现用 `markdown-it` + `highlight.js` + `v-html`，**这三样都依赖 DOM、只在 H5 可用**；将来上小程序时只替换该文件内部实现，调用方（题干 / 选项 / 解析）一行不改。
- **`src/types/index.ts` 是 `quizzy-web/src/types/index.ts` 的镜像**：移动端不引共享包，两份必须**逐字一致**，改一侧就要同步另一侧（CI 有 `diff` 守卫）。类型的真相源是 springdoc 运行时输出，不是这两份文件。

## 登录与鉴权

- 复用 `POST /api/auth/login`（用户名密码），拿**无状态 Bearer JWT**，与 PC 同一套；token 存本地 key 仍为 `quizzy_token`。
- 微信登录（`wx.login → code2session → 账号绑定`）**后置**，不在此展开，见 `docs/todo/`。

## 部署

- H5 计划走**同域子路径 `/m/`**（与 PC 同域名），因此**不需要新增 CORS**；当前**未设** `base`（保持 `/`），等真要上线时改 `manifest.json` 的 `h5.router.base`。
- **不做 PWA**（不引 manifest / Service Worker）；类 App 体验交给小程序。
- 小程序需要 HTTPS + 已备案域名 + 微信「request 合法域名」白名单——**备案是外部前置**。
