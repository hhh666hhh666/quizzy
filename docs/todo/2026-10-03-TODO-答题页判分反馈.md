## PC 端提交后不显示判分反馈（已实测）

**现象**：PC 端答题页点「提交本题」后，只看到「第 N / M 题 · 已得 X 分」在变，**没有**「回答正确 / 回答错误」「正确答案」「解析」中的任何一块。

2026-10-03 在本机 `quizzy-web` dev server（5173）+ 真实浏览器实测：勾 A/C 提交（判对、得 2 分），提交后页面文本里搜不到「回答 / 正确答案 / 解析」。
这等于**「即时判分、马上看解析」这条核心定位在 PC 上没实现**。

**根因**（代码级）：`quizzy-web/src/views/QuizView.vue` 的 `onSubmit()`：

```js
feedback.value = await submitAnswer(sessionId, question.questionId, answer)
await load()
feedback.value = feedback.value        // ← 自赋值
```

`load()` 末尾会调 `syncPicked()`，而 `syncPicked()` 第一句就是 `feedback.value = null`。
所以那句自赋值写回的是 null，反馈被永久置空。

⚠️ 连带还有第二个后果：`load()` 会把当前题挪到「第一道未答题」，于是**提交后自动跳到下一题**；
若此时反馈又没被清掉（如移动端首版实现），就会出现「题干是下一题、解析是上一题」，且「下一题」按钮会**跳过一道未答题**。

**可选方案与倾向**：

- **甲（倾向）** 照移动端已实测的写法改——提交后**停在这题**、把反馈贴回去：
  ```js
  const result = await submitAnswer(...)
  const index = current.value
  await load()
  current.value = index
  syncPicked()
  feedback.value = result
  ```
  移动端 `quizzy-mobile/src/pages/quiz/index.vue` 就是这么写的，已在真实浏览器验证：
  提交后停在第 1 题、反馈与题干对得上、「下一题」只前进一格。
- **乙** 只把自赋值改成 `feedback.value = result`（最小改动）：反馈能显示了，但**仍会跳到下一道未答题**，
  题干与反馈错位、按钮语义也乱。本次已在移动端复现过这个组合问题，**不建议**。

**为什么现在没直接改**：本轮范围是「PC 端完全不动」（[ADR 0019](../adr/0019-mobile-clients-with-uniapp.md)），
改 PC 属跨出本轮；改动本身只有几行，但应由主人点头，且两端行为应对齐。
