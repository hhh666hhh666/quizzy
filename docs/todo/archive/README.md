# 已归档的待办

这里放**已结案**的待办（文件头 `状态` 为 `已解决` 的那些）。它们早已离开 `docs/todo/` 的主索引表，留在这里只为「下次遇到同一现象时，知道当初纠结过什么、最后怎么定的」。

定这条规矩的是 [ADR 0025](../../adr/0025-archive-resolved-todos.md)。

## 归档三步（每次结案照做）

1. 把待办文件头那行 `状态` 改成 `已解决`。
2. `git mv docs/todo/<文件> docs/todo/archive/<文件>`——**文件名不改**（日期是创建日期）。
3. 改两处引用：
   - 文件内所有 `../` 相对链接**多退一级**：`../adr/…` → `../../adr/…`、`./README.md` → `../README.md`、`../README.md`（docs 根）→ `../../README.md`；
   - 把主干 `docs/todo/README.md` 索引表里那一行，从主表移到「已归档」区，链接换成 `./archive/<文件>`。

> 第 3 步最容易漏——漏了 `scripts/check-doc-links.sh` 会在提交前报红，那是唯一能机械兜住它的守卫。
