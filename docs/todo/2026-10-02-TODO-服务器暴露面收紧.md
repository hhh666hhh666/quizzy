# 待办：服务器暴露面收紧

创建：2026-10-02 · 状态：待办 · 优先级：中

## 那台机器上有三个「能少开就少开」的口，现在都开着

上云之后这台机器要承载一个**公开注册**的服务（[ADR 0017](../adr/0017-public-signup-service.md)），
所以任何「顺手开着」的入口都值得重新审一遍。2026-10-02 实测到三处：

| 入口 | 是什么 | 实测状态 |
| --- | --- | --- |
| `7891` | 宝塔面板 | 监听 `0.0.0.0:7891`，对公网开放 |
| `888` | 宝塔自带的 phpMyAdmin（`root /www/server/phpmyadmin`） | 公网可达并返回 403——**有东西在挡不等于没人能进**，仍需确认它挡的是谁 |
| `80` + `Host: 127.0.0.1` | 宝塔的 `phpfpm_status.conf` 里 `stub_status on` | 服务器本机实测 `200`，吐出 nginx 连接计数。该文件只有 `allow 127.0.0.1;` **没有 `deny all;`** —— 按 nginx 语义，未匹配的源地址走默认动作 = **放行**，所以带这个 Host 从公网大概率也能读到（⚠️ 荧无法从外部实测：沙箱的 HTTP 代理会吃掉自定义 `Host` 头，这条是「配置语义 + 本机实测」推出的结论，不是外部验证） |

**为什么现在定不下来**：收紧方式取决于主人的使用习惯——面板是常用还是备用、会不会换出口 IP、
有没有可能从手机上看面板。这不是技术问题。

**可选方案与倾向**：

- **A（倾向）按来源 IP 收紧**：面板里配置面板与 phpMyAdmin 的「授权 IP」；`phpfpm_status.conf` 补一行 `deny all;`。
  代价：换网络（出差、手机热点）时要回来改一次。
- **B 只走 SSH 隧道**：面板端口不对公网开放，要看时 `ssh -L 7891:127.0.0.1:7891`。
  最干净，代价是每次多一条命令。
- **C 先不动**，接受现状。⚠️ 但 `stub_status` 那一条**至少**值得补 `deny all;`——它是纯多余的暴露，补上零代价。

⚠️ **注意**：`phpfpm_status.conf` 是**宝塔自己的文件**，面板升级或某些操作可能把它重新生成掉。
补了 `deny all;` 之后要记着这一点，别以为它会一直在。

## 顺带一条：这台机器已经在被公网扫描了

同批还看到错误日志里的两行，来自两个不同的公网 IP：

```
request: "GET /.env.testing"       ← 找泄露的密钥文件
request: "GET /actuator/health"    ← 专门找 Spring Boot
```

**好消息是实测确认这些路径到不了后端**：后端容器不发布端口，宿主 nginx 转发给容器 nginx 之后，
只有 `/api/` 会被转给后端，而 `/v3/api-docs`、`/actuator/*`、`/swagger-ui.html` 一律落到容器 nginx 的
`location /` → `try_files` → SPA 的 `index.html`。

这一点已用探针实测过（在 8081 上临时放一个应答容器，请求这些路径时它收到的是 200 而不是后端响应）。
所以扫描是噪音，不是漏洞。**这条不需要动作，记在这里是为了下次再看到类似日志时不必重新推一遍。**
