# 待办：镜像 tag 与分发

创建：2026-09-20 · 状态：暂缓 · 优先级：低

## 2026-09-24 更新：三个问题里有一个半已经有了答案

CI 落地后（ADR 0013），原先挂着的三个问题进展不一：

- **构建放在 CI 还是本机手动推** → **已定：CI**。GitHub 托管 runner 上已经在稳定构建两个镜像，构建既不发生在开发机上，也不依赖本机网络。剩下的问题只剩「推到哪」。
- **打到哪个 registry** → 前半句要修正。原来写的「Docker Hub 在本机不通」是**本机**的限制（ADR 0010，且仅针对基础镜像的 `auth.docker.io`），CI 在境外 runner 上直连正常，所以 Docker Hub 重新成为候选。另外**可以**配 Docker Hub 账号 PAT（secrets `DOCKERHUB_USERNAME` / `DOCKERHUB_TOKEN`）把拉取限额从「匿名 100 次/6 小时按 IP 计」提到「200 次/6 小时按账号计」——**目前尚未配置**，CI 的登录步骤会自动跳过，不影响运行。
- **tag 用固定版本号还是 git sha** → 仍未定，CI 目前不推镜像，tag 固定 `0.1.0`。

**状态保持「暂缓」**，触发条件不变：**出现第二台需要跑这套东西的机器**时，再连同 registry、tag、拉取凭据一起决定。
