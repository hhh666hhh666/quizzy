## 域名已有、尚未 ICP 备案；这是移动端上线的唯一不可压缩关键路径

**现状**：域名已购买，**ICP 备案尚未完成**。境内服务器上，H5 与微信小程序**都**要求 HTTPS + 已备案域名；小程序另需在微信公众平台配置「request 合法域名」白名单（必须是备案域名、不能填 IP）。

**为什么现在定不下来**：备案是外部流程，不受代码进度控制（[ADR 0017](../adr/0017-public-signup-service.md) 估约 1–3 周）。执行者只能推进、不能压缩。

**可选方案与倾向**：

- **按既有计划推进**（倾向）：备案通过 → 域名解析 → 宝塔申请证书 → 80 跳 443。证书的申请与续期交给宿主宝塔（[ADR 0016](../adr/0016-cloud-deploy-with-release-pipeline.md) Amendment 1），不自建 acme.sh。
- 先只上 IP + 自签证书：⛔ 小程序**不接受** IP，等于没解决。

⚠️ **只卡上线、不卡文档与工程搭建**：`quizzy-mobile` 可以先开发、本地 / 局域网自测，不必等备案。

**备案通过后要一起做的**：

- 微信公众平台配置「request 合法域名」白名单
- 公安备案（备案通过后 30 日内，见 [ADR 0017](../adr/0017-public-signup-service.md)）
- `docs/operations/deployment.md` 补 H5 `/m/` 的对外入口
