# 多选题必须全对才得分

多选题的作答必须与正确答案集合完全一致（顺序无关）才算对，少选、多选、错选一律不得分，不做部分分、也不倒扣分。刷题的目的是把知识点记全，给「记住一半」发一半的分，等于用分数掩盖了没记住的那一半。

## Considered Options

- **按选中比例给部分分**：看似公允，但会让「只记得两个选项」和「全都会」在分数上只差一点，错题本的入本判定也会跟着失真。
- **答错倒扣分**：考试里常见的防蒙策略，练习语义下只会让人不敢下笔，与 ADR-0001 冲突。
- **全对才得分**（选定）：判定规则简单、可预测，且与「是否掌握」的状态一一对应。

## Consequences

- 「少选也算错」这条必须在答题界面上说明，否则用户会当成 bug 报过来。
- 正确率的分母是已作答题数，跳过的题不影响，因此不存在「不答保平安」的投机空间。
