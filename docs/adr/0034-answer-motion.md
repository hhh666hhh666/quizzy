# 移动端答题页的答对反馈动效

Status: accepted

主人提出「答对时加特效」。这与既有基调正面冲突：`PRODUCT.md` 写着「不营销、不游戏化：没有徽章、排行榜、连续打卡、成就体系」，Stitch 生出的 Quiet Focus 设计系统也写着「Zero gamification, calm, functional」；但同一页留了一条口子：「**个别『正向 / 达成』时刻可用鼓励**」。

主人经两轮拍板（grill-with-docs），本卡定：**答对那一刻加一组克制的正反馈动效**（不是庆祝特效），以及它的边界。

## Considered Options

- **庆祝型特效（彩带 / 粒子 / 屏幕闪光）**：爽感最强，但直接撞「不游戏化」，要连带改 `PRODUCT.md` 与 Quiet Focus 的调性；且小程序端要另写 canvas 组件。**否**——主人要的是「有反应」，不是「热闹」。
- **连击分级制（连对若干题升档）**：层次感好，但「连续答对」正是 `PRODUCT.md` 明确排除的「连续打卡」语义，也与 Quiet Focus 的「No streaks」冲突。**否**。
- **只做答对侧、答错保持瞬时硬切**：最省事，但同一屏两套手感（一个丝滑一个硬切），答错会显得「卡了一下」。**否**。
- **答错侧也上庆祝元素（跳动等）**：失败时刻做庆祝性动画，观感像惩罚。**否**。
- **引动画库（Lottie / GSAP 一类）**：表现力强，但为一个低频、短时、单一场景的动效引入依赖不划算；PC 端重建时已否过带 GSAP 的 taste-skill，口径保持一致。**否**——用 CSS 过渡 + 关键帧，另加约 20 行 JS 做数字滚动。
- **克制的质感动效 + 两侧统一基础过渡**（选定）：状态变化一律用 CSS 过渡（可被打断），只给「正确勾」一条带过冲的弹入；其余元素（选项染色、徽章、进度条、按钮文案）共用同一条曲线与时长档位。

## Consequences

- **范围**：只移动端答题页。PC 端、结果页、其余页面本轮零改动（PC 已有自己的动效体系，等移动端验收后再议是否同步）。
- **时机**：只在「提交判对那一刻」放一次；快速练习 / 错题本 / 试卷三个来源一致；**回看已答对的题不重播**——回看是静态复习，动画不能变成每次进页面都自嗨一遍。
- **动效清单**（时长与缓动以 `quizzy-mobile/src/uni.scss` 的动效 token 为真相源，本卡不抄值）：选项与标记平滑染绿 → 正确勾弹入 → 徽章淡入上浮 → 得分数字滚动 → 进度条与整卡切换平滑 → 按钮文案极短淡入。
- **庆祝元素归答对独有**：错叉只淡入，不带弹性、不滚动；答对与答错共享同一条基础过渡曲线。
- **无障碍地板**：`prefers-reduced-motion` 必须生效——CSS 层在 `App.vue` 全局兜底（动画压到 0.01ms、过渡只留颜色类，与 PC 端 `tokens.css` 同口径），JS 驱动的数字滚动在调用处另判一次 `matchMedia`。⚠️ 小程序端目前不是编译目标，真上时要复核 `@media` 支持情况。
- **动效从不单独表意**：颜色、徽章文字、「正确答案」一行始终在（ADR 0033 的这条硬约束继续有效）。
- **无音效、无震动**。
- **未做（落待办）**：里程碑时刻（「掌握」、整卷满分）要不要放大一档——见 `docs/todo/`。
- **术语不动**：这是交互工艺、不是领域概念，`CONTEXT.md` 不新增词条；`PRODUCT.md` 也无需改（本方案正落在既有「正向时刻可用鼓励」的口子内）。

## Amendment 1（2026-10-12）：幅度加强、绿环涟漪、「刚提交」门控与闪烁修复

上线后主人反馈两点（「看不出动效」「提交时画面闪一下」），据此调整——档位没变，仍是克制路线：

- **幅度加强**：状态过渡 240→320ms、勾弹入 300→420ms 且过冲从 6% 加到约 22%、徽章上浮幅度加倍、
  得分数字滚动延到 600ms；另给正确答案的标记加一圈**淡出的绿色涟漪**（仍属「答对独有」）。
  时长与缓动的真值仍在 `quizzy-mobile/src/uni.scss`，本卡不抄值。
- **「刚提交」门控**：庆祝类动画加 `celebrate` 开关，只在该题「刚提交判分」那一刻播；
  **回看已判分的题不再重播**。原实现漏了这道门控（回看时勾 / 叉也会播一次），本次一并修正——
  Consequences 里「回看不重播」的结论不变，是把它真正落实。
- **提交闪烁修复**：提交后刷新会话改为「保持当前题」——原逻辑先把位置挪到「第一道未作答」再挪回，
  中间态把题卡重挂载两次（被切题淡入动画放大成肉眼可见的闪烁）。
