# 用「归属为空」表示公开题

题目不归属任何人时就是公开题：所有人可见、谁都不可改；归属某个用户时只有本人能改。用「没有归属」这个状态来表达公开，而不是加一个 `is_public` 开关——这样公开题天然没有主人，不会出现「这道公开题归谁管」这类需要额外处理的情况。

## Considered Options

- **加 `is_public` 布尔字段**：读起来更直白，但会出现「归属是张三、同时又是公开的」这种需要额外约定才能解释的状态，编辑权限的判定也要多绕一层。
- **单独建一张公开题表**：彻底隔离，代价是题目查询、导入、统计全部要写两遍。
- **归属为空即公开**（选定）：权限判定收敛成一句话——能改，当且仅当归属是自己。

## Consequences

- 所有题目查询都必须带「归属为空 **或** 归属为我」的条件。这是最容易漏写的一处逻辑，新增查询时要特别留意。
- 用户目前**无法**把自己建的题设为公开，公开题只由种子数据产生。这是有意的收窄：一旦开放，就要处理「某人删掉一道别人正在练的公开题」这类问题。
- 后来者容易误以为「归属为空」是数据缺失，值得在术语表里写清楚它表示公开。
