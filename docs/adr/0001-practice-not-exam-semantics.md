# 练习语义优先于考试语义

v1 的定位是个人自学刷题：答完立刻看对错和解析，答错的题进错题本反复练。所以做了逐题即时判分，同时明确不做限时、防作弊、监考、成绩排名这类考试语义的东西。一个人刷题时，「防人」所需的全部工作量都是纯负担，而它挤占的正是让人想继续练下去的那部分体验。

## Consequences

- 未作答的题不算错，只在结算时提示数量。口径来自「练习」而不是「考试」——练习里跳过一道题是正常的，不该被罚。
- 如果以后要接考试场景（班级测验、认证考试），这会是第二个产品形态而不是开关：限时、防切屏、成绩存档会改变会话的整个生命周期，硬塞进现在的会话里只会两件事都做不好。
