# 正确答案存在题目上，而不是给选项打标记

一道题的正确答案以「选项标号的集合」形式存在题目自身（例如 `A,C`），而不是给每个选项加一个「是否为正确答案」的标记。这样判分就是把两份集合直接比对，看题目时能一眼看到答案，导入导出也不必为了找答案去扫一遍选项。

## Considered Options

- **给选项加 `is_correct` 标记**：建模上更"关系型"，但答案变成散落在多行里的东西：要读答案得扫选项、判断题要校验恰好一个为真、多选题要校验至少两个为真，导出模板也会多一列。
- **存在题目上**（选定）：答案与题目一对一，判分逻辑与存储格式同构，导入导出都只需处理一个字段。

## Consequences

- 选项与答案的一致性靠保存和导入时的校验保证（答案必须存在于选项标号中），数据库层面没有约束兜底。新增写入路径时要把这段校验一起带上。
- 删除或重排选项时不会出现孤立的「正确标记」，但必须重新校验答案是否还在选项里。
