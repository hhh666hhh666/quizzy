# 工作台：答题记录列表加「放弃作答」

## 意图
主人选方案 A：历史列表（HistoryView）给「进行中」会话加「放弃作答」操作，复用现有 `POST /sessions/{id}/abandon` 接口，纯前端改动。确认弹窗文案与 QuizView 的 onAbandon 保持同款语言（confirmBox，danger）。

## 结果
HistoryView 进行中会话的操作列加「放弃作答」（confirmBox danger 确认 + abandonSession + toast.success），筛着「进行中」时弃答后退回「全部」并写回网址；typecheck 绿、check-doc-links 全绿；`docs/design/前端.md` 与 `docs/requirements/scope.md` 的历史页描述同步「或放弃作答」。
主人截图反馈看不到按钮 → 核实为浏览器持有旧页面（截图操作列只有一个链接），代码本身已满足「字号不变、放右边」：与「继续作答」共用 `link-button`（只有圆角+焦点环，无字号），继承表格 `text-sm`，未再改代码，等主人强刷确认。
主人强刷后按钮出现，但反馈「很多列往左偏」→ 根因是表格用自动列宽，操作列加按钮后把中间各列往左挤。修复：`table-fixed` + colgroup 固定比例列宽（ID 7% / 标题剩余 / 来源·状态·得分 10% / 开始时间 17% / 操作 19%），标题列截断兜底、`min-w-[880px]` 窄窗横滚。用 playwright-core 直驱本机 Chrome 在 1280/2560 两档窗宽实测截图（`.workbuddy/hist-layout/`），列宽比例符合设计；临时验证用户（id 301）及其两场会话已从 dev 库删净，直驱脚本已删。
