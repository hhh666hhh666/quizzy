浮层（玻璃）

玻璃是**第二套语言**，只用在「确实浮在页面之上」的东西：弹窗 / 抽屉 / 下拉 / 提示， 以及表达型页面（登录 / 结果 / 空态）。铺底永远用上面的「面」，不用玻璃。

↑ 这是「页面内容」（一块有色的面）

这就是玻璃浮层

注意它背后有东西可透，所以看得出是玻璃。若它浮在纯白上，就几乎看不出来——那是白付性能。

轻玻璃（.glass-bar）：顶栏 / 侧栏用——半透明但不模糊，滚动时看得到内容透过去。

⚠️ 玻璃上**只放短文字**（标题 / 按钮 / 标签）；题干与解析永远放在近白的「阅读面」上。
